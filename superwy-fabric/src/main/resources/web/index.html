保存仓库区域

 
取盒与定期背包存箱
超过 25 格自动用潜影盒打包；每次只取 1 个空盒。货盒达上限交付，收货假人满后换 _1、_2。累计完成交付 50 轮后，打开清理箱存入主背包 27 格余物；快捷栏、装备和副手保留。计数持久保存，批量任务算一轮；箱满保留余物并提示，恢复空间后下次交付重试。

 
已保存区域
各区域独立开始、停止并保留断点；多个运行区域轮流推进，无需等另一区域扫完。单独停止后不会被定时任务或全局开关重新启动，历史库存仍可取货。




创建物品清单
按缓存定位货源，优先打开地面潜影盒。超过 25 格自动打包，携盒达上限即原地交付后继续。每完成交付 50 轮，将主背包余物存入清理箱。
最近订单详情
选择订单查看每行取货数量、装箱交付与收货证据。
订单队列
保留全部进行中订单及最近 10 条已结束记录，更早的历史记录自动移出此列表。
普通单执行最多 500 秒，打包单最多 24 小时（不含排队，仍受订单有效期约束）。取消即停止本单并移出队列，物品留在原位；异常立即结束本单；缺货会在游戏内公告物品 ID。每单执行前自动关闭空光标容器界面；光标有物品时保留现场并停止，请先处理残留物品。

调度状态
读取调度状态…
名为调度机器人的那台负责排队、派活并参与取货，其他机器人自动找到它。单项取货优先派给空闲机器人；批量按块分派、整单排队。掉线超过改派时间未回来，未交付部分改派给其他机器人；回来后继续原任务块。所有机器人都要用主人的 private jar；玩家需在取货端执行 /swrequest mesh on。在任何一台机器人的网页都能管理，操作会转给调度机器人执行。

FRP 公网连接
读取连接状态…
本机自动分配空闲端口，公网随机端口冲突后自动重选。停止隧道不停止游戏取货。连接指令只授权填写的收货假人。




玩家执行后弹窗填写收货假人名，默认 sf，可在取货设置修改。每次生成独立玩家凭证；公网端口会持久保存，冲突换号后请重新生成。旧订单不会自动重发。私聊下单已停用，玩家端需 0.6.0 或更新版本。


外部程序接入
玩家 mod 和脚本使用 HTTP JSON 请求同一接口。每个请求提交物品清单和收货假人名称，并携带持久保存的幂等键。
POST /api/v1/orders
Authorization: Bearer <token>
Idempotency-Key: build-20261025-001
Content-Type: application/json
